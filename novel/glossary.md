# 《平凯仙录：云起分布式》术语对照与设定集

没学过 TiDB 也能读。正文里每遇到新招式，玄衡真君都会先打比方，再点一次正式名字。本表只做备查，不必先背完。

全书修仙称谓固定，后续章节不得另起别名。

## 怎么读

- 把「玉简表」想成一张 Excel：行是一条记录，列是字段。
- 把「命牌」想成主键：每个人只有一个身份证号。
- 把「单机巨灵道」想成把所有数据塞进一台超级电脑。
- 把「平凯混元大阵」想成把计算、调度、存储拆开，用很多台机器一起干活。
- 正文用〔〕给修仙名词加一句白话，例如「数符〔账本上的一行〕」「玉简表〔一张有行列的账本〕」。每章同一个词只注第一次；〔〕里是人话，（）里才是英文专名。

## 全书主线（先读这个）

太数门百年大典，是把三万新晋弟子的命牌写进账本。写不进，人就是游魂。巨石宗少主石天霸带着「贺礼」内存灵石来观礼，盟约里写着：井一塌，太数门可被兼并。他要的不只是一座山门，还有太数门在大千交易所里的地契那一行。

杂役莫寻在偏殿废墟里拾到《平凯玄天录》，器灵玄衡真君只讲理、不代打。莫寻一路救人救门：先保住命牌入账，再把一口井迁进后土，再从交易所抢回地契，最后在青云仙盟的万仙论道上拆穿单机极道。石天霸咬破第一章就带着的贺礼符，放出附在符里的天魔。天魔散了，太数门改作平凯分坛，莫寻飞升。

每一章的招式，都是这条存亡线上的某一次动手，不是新开一堂课。

## 旧法与劫难

| 修仙称谓 | 技术对应 | 一句话白话 |
| --- | --- | --- |
| 单机巨灵道 | Scale-Up | 只养一台机器，出事全死 |
| 玄天单机宝鉴 | 单体数据库机器 | 内存、磁盘、CPU 全堆在同一具肉身上 |
| 磁盘告磬之劫 | Disk Full | 盘写满了，新账落不下去 |
| 锁心魔 | Deadlock / Lock Timeout | 两个人互相等对方放手，谁也走不了 |
| 天火焚神 | CPU 100% 熔断 | 慢查询把处理器烧满 |
| 识海漫灌 | Full Table Scan | 没有路标，只好把整本账翻一遍 |
| 连接池爆满 | Too Many Connections | 门口座位坐满，后来的人进不去 |
| 碎玉分身术 | Sharding / 分库分表 | 把一张大表砍成很多小库，跨库办事极难 |
| 乾坤停机大挪移 | 停机扩容 / reshard | 要搬家必须先封山停业 |

| 焚天热点暴击 | Write Hotspot | 所有人同时改同一把钥匙，那一点被写爆 |

## 硬性不变量（写作禁区）

这些规则在故事里永远成立，也是 TiDB 真正在守的底线：

1. Raft 提交必须多数派过半。三台里至少两台点头，账才算写下。网络断开时，凑不齐票的那一边不许自称掌门，禁止两边同时写（脑裂）。
2. LSM 必含三层：晨露之泉（MemTable）→ 冰心（Immutable MemTable）→ 七层金阶（SST）。整理跟不上，可以停写，不许假装能无限狂写。
3. Percolator 事务拿本命锁（Primary Lock）判生死。提交时先敲本命锁；其余副锁可以稍后根据本命锁自行了结。
4. 太初时序印（TSO）必须全局只增不减。各城墙上的物理挂钟，不能拿来当跨城先后顺序。
5. TiFlash 是 Learner：只旁听复制，不抢 Leader，也不给前台交易加行锁。
6. Region 是一段连续的主键区间，不是哈希打散的槽。默认大约 96MB～144MB 切一刀。
7. 计算层无状态：TiDB 节点不存账本，账本只在 PD 与 TiKV。莫寻识海可以化出很多法身，肉身不必自己扛数据。
