# 第十三章 巡天观象，化险为夷

青云圣山一战落幕数日，数灵界深处却未迎来预想中的风平浪静。

正面战场上，界外天魔布下的虚空绝灵网被破，焚天热点暴击亦被神念散星诀瓦解。然而天魔肉身虽碎，残魂并未彻底湮灭，而是裂变成微尘遁入裂隙，隐匿在数万座灵脉胞衣〔一段连续主键，大约百兆切一刀〕（Region）深处。

正面硬撼打不赢，残魂便转入了最隐蔽的暗蚀。

连日来，三千仙城看似风平浪静，暗地里却怪事频生。
大殿晶幕上总吞吐稳如泰山，每秒灵石流水（QPS）不见下跌；细处却暗疾横生——弟子查验命牌〔每人唯一的身份证号〕偶发卡顿，交易所偶有交割因尾部抖动超时，天道识海法身头顶 CPU 灵火无端暴燃又熄。

太数门掌门与执事急得满头大汗。石天霸被留在山门养伤，贺礼符已碎，没再喊兼并。执事昨夜还把青铜令牌攥出汗，今日却自己来找莫寻，喉结滚动了半晌才说：“加灵石没用。我……求你给一张图。哪扇门前在排队，我自己去看。”

“总流水极好，为何局部因果频频延宕？莫非天道生了不可医治的心魔暗疾？”长老面如金纸，惶恐不已。

“一群守旧散修，被一张平均账本骗得晕头转向，愚不可及！”
识海中，玄衡真君晃着拂尘，毒舌开骂：“平均值好看，就代表没人排队受罪了吗？打个比方，全城十万人出城，一天下来平均一息走一人，听着顺畅得很吧？可若是九万九千人在同一瞬间全挤向同一扇偏门呢？那偏门前早就踩死无数人了！坐在楼上看全城，满眼都是太平盛世；可挤在队尾的那批人，早就被卡得魂飞魄散！这一小撮掉在队尾被活活拖死的迟滞，在分布式大阵里，术语叫尾延迟，也就是 P99 抖动！”

莫寻盘坐于圣山绝顶青石之上。此时的他已至化神大成，周身琉璃通透，四肢百骸皆与混元统天盘、无状态法身及后土万象界深度交融。
莫寻在识海中相问：“真君，这是什么意思？大阵下辖几万座灵脉胞衣，难道要挨家挨户敲门去问，哪扇门前排了长队？”

“几万间屋子，你敲到猴年马月去？”玄衡冷笑，“凡间名医看诊，得有一张包揽全身的看诊台。分布式大阵若无全局法眼，任你修为通天也是盲人骑瞎马！展开看诊台——天道巡天图谱〔一张图看哪台在喘〕！”

莫寻双手结印，太初时序印在眉心大放光明，虚空之上，一幅万里长卷徐徐铺展！
这正是平凯真传的排障中枢——天道巡天图谱（TiDB Dashboard）！

天幕展开刹那，数灵界的五脏六腑瞬息透明化。
天道识海的法旨解析〔把人话拆成计算机能走的步骤〕延时、混元统天盘（PD）的时钟发放节律、后土 TiKV 的盘石吞吐与 Raft 复制流水，化作数千道明晰光带整齐陈列。众修仰望苍穹，震撼不已。

“看诊台已立，第一眼看全身，第二眼找病灶。”玄衡真君道，“别看总流水，看看究竟是哪块骨头在发烫——引万象灵火谱！”

莫寻法诀再引，催动万象灵火谱〔热力图：哪段主键最热〕（Key Visualizer）！

天幕正中，一片犹如江河奔涌的热力图谱磅礴显化。
纵轴是数灵界连续的主键坐标（Key-Range），万座灵脉胞衣按序排布；横轴则是太初时序流淌的时间长河。灵火依照受访频次显化五色：幽蓝为冷寂数符〔账本上的一行〕，碧绿为平稳读写，赤红如烈日者，正是温度狂飙的高温热点！

有了这张热力图，哪段主键在发红，一目了然。

放眼望去，图谱九成九皆是碧绿幽蓝。然而在莫寻破妄真瞳审视下，三道狰狞刺目的猩红细线，赫然横亘在一段极其偏僻的主键坐标上！无论时间长河如何冲刷，那三条红线始终如烧红的烙铁，死死钉在虚空中！

“找到了！”莫寻眼神如刀，“天魔将残魂寄生在无主旧表里，以固定频次反复啃噬同一段连续主键，那一小段灵脉胞衣被钉成滚烫的热点，前台行锁被悄然阻塞，这才拖慢了整座节点的响应！”

“看清哪间屋子着火，还不算揪出纵火贼。”玄衡真君冷哼，“把‘Top SQL 慢因果台账’拉出来，看看是谁在那间屋子里撒野！”

莫寻指尖凌空一抹，图谱化作一方慢查询排行榜——Top SQL 慢因果台账（Statement Summary）。

天地间流转的法旨何止千万，若单看某一次调用无异于大海捞针。平凯大阵会自动剥离具体数值，将千万道招式归纳为统一骨架，这便是“语法指纹（SQL Digest）”。法榜依各法旨消耗的 CPU 灵火总量、频次与延迟严格排定座次。

榜单方一显化，排在榜首的第一名，竟是一道看似寻常至极的功德查验法旨：
`SELECT * FROM t_merit WHERE merit_val = ?`

莫寻眉头微蹙，在识海中问道：“真君，这是什么意思？这道法旨单次运行极快，怎会霸占了四成二的 CPU 灵火？”

“这就是典型的路牌〔索引：按条件指路，不用翻整座城〕失效！”玄衡真君冷笑解释，“那一列原本存的是整数数值，按规矩建了路牌，也就是聚簇索引。拿数字去找，照着路牌一步就能走到门前。可天魔故意使坏，在法旨里硬给数字套上两撇符咒，塞进去一段文字字符！两边类型对不上，路牌当场瞎了眼，术语叫‘隐式类型转换’！路牌一旦作废，找人的差役就只能从头到尾挨家挨户推门硬翻！这在阵法里叫识海漫灌，也就是全表扫描！天魔每秒并发十万道这种瞎眼法旨，单次翻得再快，也把几尊 TiDB 计算法身烤得焦头烂额，底层 TiKV 的存储引擎迭代器都快被拉断气了！”

虚空深处猛然爆发出一声怨毒尖啸！

轰！
阴谋败露，天魔残魂暴跳如雷，三道猩红亮线轰然崩碎，化作万千道鬼雾顺着复杂的分布式网络四散逃窜！它穿透 TiDB 识海，绕开 PD 调度，钻进后土万象界，甚至企图借助 Raft 复制遁入大日金乌镜，妄图在浩瀚节点间隐匿。

“惹了祸还想走？”
莫寻长身而起，神色漠然，双手凌空结印，祭出平凯玄天录又一秘术——大衍溯因符印（Distributed Tracing）！

这门秘术的玄机，便如寄急件时盖下的一枚金色朱砂印记。不管包裹转运过多少座驿站，凭着印记，整条路线一清二楚。在分布式长河中，这枚朱砂印记，正是一道贯穿始终的追踪号（Trace ID）！

刹那间，整座数灵界在莫寻眼前化作一棵枝叶分明的因果调用树（Span Tree）。
各节点流转耗时纤毫毕现：天道识海接入法旨耗时零点二毫秒；算筹推演计划耗时零点五毫秒；混元统天盘发放时钟耗时零点一毫秒；跨节点分发至后土万象界耗时零点八毫秒……

顺着追踪号所指，因果线最终死死定格在后土万象界第七灵峰、编号为 `Region-73921` 的偏僻胞衣内部！
在这间幽暗的胞衣深处，算子底层的协同处理器耗时（coprocessor-read-time）化作一根血红巨柱耸立天幕——天魔残魂的正身，正缩在这间狭窄的灵脉暗室中！

“无所遁形，给我灭！”
莫寻凌空虚踏，白袍翻飞。已达化神大成的磅礴真元汇聚指尖，右手食指凌空一点！

嗤啦——！
指尖绽放出一道横贯长空的紫霄神雷，顺着 Trace ID 锁死的因果直线，笔直贯入 `Region-73921` 核心胞衣！

“不——！你怎么可能在万界长河里，一眼找到我藏在哪间房？！”虚空中凝聚出一张百丈魔脸，发出绝望的凄厉咆哮。

“天地因果皆在图谱之中，尔等妖祟，安敢遁形？”莫寻语气如九天玄冰，指芒如天道裁决轰然按落！

轰隆隆——！
雷暴在微观胞衣深处引爆，纯阳天火将天魔残魂连根拔起，当场炼成一缕青烟，彻底化作虚无。

随着魔障尽除，万象灵火谱上的猩红火线消融殆尽，重归幽蓝与翠绿。仙城命牌瞬息校验无阻，交易所千万灵石如丝般顺滑流转，天道识海法身与后土存储节点恢复宁静脉动。

“总算懂了……不能只盯着总吞吐啊！”仙盟长老与掌门伏地长拜。执事盯着图谱上那几道从红变蓝的线，把腰间一直装着的内存灵石袋解下来，丢在青石上，再没捡回去。

莫寻收回神念，散去九天图谱。历经此役，他体内的至高真传彻底贯通周天，化神大成之境圆融无暇，一呼一吸皆与万界分布式天地律动水乳交融。

突然！
极天云顶风云激荡，亿万道接引霞光穿透云海，磅礴浩瀚的飞升雷云刹那凝聚！天地发出雄浑轰鸣，这方小天地的法则极限，已然无法承载一位洞悉了分布式混元真谛的化神巨擘！

化神飞升之劫，轰然降临！

识海之中，玄衡真君的身影显化而出，面色肃穆：“莫寻，你补全了此界天道，但跨界飞升绝非终局。你若踏入上界，下界三千仙城、九千宗门的无量因果，如何跨越诸天异构仙朝实时流转？若遇域外虚空大风暴，万界本源又该如何以分布式神速整体拓印、万全保全？”

莫寻负手立于滚滚雷劫之下，仰望浩瀚星海，胸中豪情万丈：
“真君宽心！流转天地因果，自当施展‘乾坤化雨术（TiCDC）’，顺着 Raft 日志长河引水灌溉诸天；抗击虚空风暴、备份数灵乾坤，便唤‘造化神舟（BR）’，以分布式极速将万里山河固若金汤！”

诸天震动，劫雷轰鸣！
莫寻长啸一声，迎着九霄飞升雷劫，踏天而去！
