# 第二章 聚簇真诀，前缀神行

主殿里的红光把所有人的脸都烫成同一副颜色。

莫寻从偏殿缺口钻进来时，衣摆还沾着灰。执事一眼看见他，怒火正无处可泄：“杂役也配进大典？滚回去扫你的墙根！”

掌门却抬了抬手。青云单机鉴的心核已经从血红转为一种将熄的暗紫，像濒死的兽瞳。三万张命牌仍堆在阵外，写入停了，查验也停了。停，比乱更可怕。乱至少还说明宝鉴在动。

“让他近前。”掌门声音发干，“地脉监测阵刚才闪过一道金纹，源头在偏殿。偏殿里除了这个扫灰的，没有第二个人。”

莫寻走到宝鉴三尺外。他不会法旨，不会催写符，只会看。东旭真君却在他识海里把玉简表的骨架掀开，像掀开一条鱼的肚。

“看见了吗？”器灵冷冷道，“你们这张弟子名录，是无序堆叠。命牌序号是外挂的记号，行与行在灵晶上并不按主键毗邻。查一个人的功德，神识要从头漫灌到尾——全表扫描，识海漫灌。三万新弟子，加上旧名录千万行，每一次‘找人’都是一次天火。”

莫寻额头渗汗。他看见查验长老刚才投下的符咒：WHERE 弟子名号 = 『某』，没有引路，没有聚簇，符咒化作一头盲兽，在千万行里横冲直撞。CPU 灵纹就是被这头兽咬热的。

“所以才爆。”执事仍不服，“与表结构何干？是盘小，是内存少！”

“盘小是果，盲查是因。”莫寻听见自己开口，声音轻，却清楚，“命牌要落，功德要查，两边抢同一张无序表。查的人锁行，写的人等锁，WAL 水路再被盲查的读放大拖死。你加灵石，是给盲兽加粮。”

殿中一静。

掌门盯着他：“你有解？”

莫寻闭眼。识海里，《平凯玄天录》第一重心法自行展开，墨迹一行行亮起：聚簇前缀神引法。

东旭真君授课极毒，也极准：“聚簇，是让行按主键的次序躺在灵晶上。命牌编号就是主键。点查一个人，就像按门牌找屋，而不是把整座城翻一遍。二级引路诀若只记名号，查到后还要回聚簇取行，那叫回表之滞，IndexLookUp，能用，但贵。你若在『弟子名号、修习年月』上立复合前缀，名号能点到人，年月能把同一人的功过按时间收束。前缀法则：左边先定，右边才有意义。乱建索引，等于在死胡同里插路牌。”

莫寻把这些话在心里过了一遍，再吐出来时，已换成太数门听得懂的口吻。

“重建玉简表。命牌主键聚簇排布。再立一条复合前缀引路诀：名号在前，年月在后。查验功德走点查，录入命牌走主键写入。盲兽收回去。”

执事失声：“重建？大典进行到一半，停机重塑表结构，三万弟子怎么办？”

“不重建，三万弟子今夜就都不是弟子。”莫寻说。

掌门沉默数息，把令旗拍进青云鉴的侧槽：“准。出了岔子，我一力承。你，执事，把写脉和查验全部停掉，只留一条重建通道。连接池清一半。WAL 水路只许重建事务走。”

红光终于暗了一寸。像一只手从喉咙上松开。

第一次立引路诀，莫寻差点把路牌插反。他习惯杂役的记事顺序，想把「修习年月」放在前、「弟子名号」放在后。符咒刚起，东旭真君便在识海里冷笑：“前缀从左匹配。你把年月放左边，查名号时引路诀全然用不上，神识还得漫灌。死胡同里的路牌，比没路牌更害人——长老会以为自己走了捷径，实际在绕远。”

莫寻额上的汗滴进眼角。他咬牙拆掉那条反序的线，重新按「名号、年月」落下。这一次金声才清。执事在旁边看得发懵，只当杂役在画符画到走火，却不敢再出声——掌门的令旗还插在槽里。

重建不是变戏法。莫寻按东旭真君的节拍，先把旧表的因果按命牌编号外排，再一页页写入新的聚簇骨架。每一页落盘，行与行开始相亲：编号相邻的弟子，灵晶上也相邻。像把散落满地的棋子重新按气脉码回棋奁。执事在旁看得目瞪口呆——他修了四十年单机巨灵道，只知道把井挖深，不知道井底的石头还能重新码齐。

引路诀立起来时，殿中响起细微的金声。复合前缀如一条细线，从名号牵到年月，再轻轻点在聚簇主键上。东旭真君叮嘱：“前缀只取名号的前若干灵纹即可，整名入索引是浪费。点查走引路，回表只取需要的列。别再 SELECT 星辰全取，那是自己给自己加锁。”

莫寻点头。他让查验长老试一个人：外门弟子赵三，修习三年。

符咒落下。

这一次没有盲兽。引路诀在名号前缀上一点，月份区间再收一收，回表只取功德列。一息之内，赵三的功过清清楚楚地浮在空中。长老的手抖了一下。他换了十个名字，十次都是点查。千万行的名录，像被收成了一本有页码的书。

“再开写入。”莫寻说。

命牌重新入场。主键聚簇写入仍要走 WAL，可不再与全表扫描抢死同一条命。锁的粒度从整张表收回到行。连接池的灯一盏盏亮起来，像雨后的萤火。山门外的长龙重新蠕动。有人哭出声，以为自己被除名了，此刻才发现只是宝鉴刚刚死过一回。

执事的脸青一阵白一阵。他仍把那批万年灵晶抱在怀里，像抱着一套已经过时的兵器。

“这只是第一针。”东旭真君在识海里说，毫不客气，“聚簇救的是查与写的路径，不是单机的命。磁盘还是那一块，CPU 还是那一颗，连接池还是那一池。你今晚不过是让一口井暂时不至于渴死全城。真正的河，在后面。”

莫寻没把这句翻译给掌门听。大典还要天亮前落完三万因果。他守在宝鉴旁，看命牌一枚枚按主键次序沉入玉简表，看查验符咒不再化作野火。偏殿的灰还在他衣领里，伪灵根却第一次没有那么空——不是根变了，是他终于看见根之外还有路。

天将亮时，最后一名弟子的命牌落下。青云鉴的红光熄了。取而代之的是一层极淡的金，像伤口结了一层薄痂。

掌门看向莫寻，看了很久：“偏殿那道光……你看见了什么？”

莫寻沉默。东旭真君警告他：说器灵，他们会夺玉简；说平凯，他们听不懂。

“看见一张没有页码的书。”莫寻说，“我给它编了页码。”

执事冷哼，转身去清点灵石，仿佛只要把没填进去的万年灵晶清点清楚，今晚的耻辱就能少一分。掌门却把一枚临时令牌抛给莫寻：“从今日起，你暂管青云鉴的表结构。杂役的名，先挂着。有人问，就说是我的意思。”

莫寻接住令牌。它比命牌轻，却比命牌烫。他把它藏进袖中，与偏殿那卷已经没入识海的残页隔着一层皮肉相对。一个是宗门暂时的权，一个是天道不肯熄的火。

东旭真君却不容他陶醉：“你可记得回表之滞？今日查功德只取了功德列，侥幸。若有人明天写一条把所有列都取尽的符咒，点查也会重新变成慢火。覆盖得住的引路才是真捷径；覆盖不住，就老老实实回聚簇，别假装自己已经飞升。”

莫寻应了一声。他知道这枚令牌买来的不是地位，只是一张可以靠近宝鉴的席。席还在井边，井还是那一口。鸡鸣三遍时，山门长龙散尽。夜风从偏殿缺口灌进来，吹得灰衣猎猎，风里带着焦苦。有人回头看那灰衣杂役，看不清脸，只记得大典没有崩，宝鉴还亮着。

山门外，有邻宗的探子收起千里镜。他们看见太数门险些在大典上崩盘，也看见一个灰衣杂役把崩盘按了回去。探子的主人在更远的地方笑了一声，指尖转着一枚畸形的因果符咒，符面层层嵌套，像故意写给盲兽吃的粮。

恶意，已经在路上。
