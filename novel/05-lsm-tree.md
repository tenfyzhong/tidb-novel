# 第五章 后土枯荣，七阶千叶楼

暮色四合，残阳如血，太数门后山绝壁下冷风如刀。

掌门立下的“三日之约”仍在耳畔。三日内若不能将旧账与三万命牌〔每人唯一的身份证号〕迁入后土地脉，太数门便要交出地契，甘受兼并。

莫寻盘坐于翠微峰青石台，泥丸宫中无状态灵胎清光流转。

护法阵外，掌门面沉如铁；执事瘫坐一旁攥紧储物袋，冷汗淌了一脸。这是大典以来执事第一次没喊加灵石——死井已弃，灵石救不了命。

“起阵迁账！”掌门沉喝。

轰！三万道命牌清光如暴雨涌向莫寻。写不进账，人便沦为游魂！

未等命牌落稳，山门骤然暴起漫天妖芒！

“报——！”查验长老疾呼，“百草峰反了！石天霸买通百草峰伪造千万流水，借道交易所全砸向后山！他们在连夜灌账！”

掌门五指扣入岩壁。好狠毒的石天霸！定下三日之约，暗地里却连夜灌账，要冲爆后土！

千万道浑浊账目如天倾般撕裂苍穹，夹杂着三万命牌轰落！

暴烈写入狂砸而下。莫寻运转旧法吐纳试图接纳。旧法结丹讲求“原地开辟”，落盘讲求“原地寻道，就地覆写”。真元撞入穴窍，每来一笔新账，莫寻便在原处磨平旧痕重刻。

可面对千万笔灌账，刚凿出一行，后浪已如重锤轰至！穴窍晶壁在频繁覆写下布满裂纹，如频繁随机改写的残破宝鉴，莫寻喉头一甜，逆血狂喷！

“蠢材！真是蠢不可及！”

玄衡真君踏虚而出，劈头痛斥：“刚破了深渊，怎么转头又扎进了就地修改（In-place Update）的臭泥坑里？！”

莫寻咽下腥甜，咬牙急问：“真君……这是什么意思？账目落地，难道不该在原处涂改定稿？”

“你在山顶立块石碑，全城几十万人同时改名，每来一笔你都要提凿子满山跑，跑到原本那行磨平重凿？”玄衡冷笑，“几万人同时改，凿子满山乱飞寻道，光是来回跑断腿，就足以把石碑凿碎、手腕震断！单机旧法原地硬改，肉身不炸才怪！”

莫寻如遭雷击：“不在原处改，狂暴写入往何处落？”

“神随我动，下潜三千丈！”玄衡大袖一挥，拽着莫寻神识穿透千丈岩层。

雄浑的后土万象界〔真正存行数据的地方〕在眼前铺开。浩瀚流光顺着时序如飞瀑笔直坠下，井然沉入地脉，绝无原地翻凿的破坑。

“此乃上古存储大道——LSM-Tree 枯荣心法〔新账先写内存，再一层层压盘〕！”玄衡喝道，“顺势而生，绝不原地翻覆！一切新写皆顺序追加，一切沉淀循枯荣阶梯！”

玄衡真君先打比方，再点真名：“凡人掌柜在柜台接客，每来一笔生意，难道立刻抱石板去后山凿字？桌上放碗水、张草纸，客人报名字，蘸水提笔往纸上顺着记一行，随来随写，岂不快若惊雷？记满一摞再整批归档！气海之上，开辟晨露之泉〔内存里正在写的那一层〕！”

“晨露之泉（MemTable），便是内存里的草纸！顺序追加，绝不原地翻找！”

莫寻神识归窍，在气海表层化出一汪灵泉。跳表如金鱼巡游，千万灌账与三万命牌依序追加，行云流水，穴窍剧痛瞬间消散！

“得意什么？草纸就那么大，写满怎么办？”玄衡冷笑。

百草峰灌账太猛，晨露之泉眨眼漫过堤岸！莫寻急道：“真君，草纸写满了！若是边接客边搬运，岂不两头大乱？”

“写满就拍上镇纸，让它冻住变死物！”玄衡喝道，“这一页只准查阅、准备落盘，不许添新字；桌上立刻抽张新纸继续接客！动静两分，冰心〔写满后冻结、准备落盘的内存层〕（Immutable MemTable）！”

“凝！”莫寻引动冰魄，晨露之泉瞬间冻结，化为剔透的冰心（Immutable）。泉眼下方再响，一汪全新晨露之泉凭空开辟，无缝接引狂涛！

“冰心已成，沉降后土！筑七层金阶〔磁盘上分层整理过的文件〕，立千叶楼！”

冻结的冰心化作规整玉简沉入底层。七道玄黄石阶拔地而起，正是磁盘上的七层金阶（SSTable/SST）！

冰心首先落入顶层的零号金阶（L0 SST）。但数十块冰心接连砸下，玉简堆积如山，区间重叠混乱！莫寻神识一探，要在零号金阶每块玉简里逐一翻找命牌，深陷泥沼！

“这叫读放大（Read Amplification）！”玄衡道，“写满的草纸堆在门槛上，想找一笔账得把每张纸翻一遍！零号金阶未经梳理，必须以地火行‘淬火归并（Compaction）’！像铁匠打铁，把生铁扔进炼炉重新熔炼，理顺区间，把百草峰灌来的作废旧账和墓碑当场烧尽！”

“起火！”莫寻引动地火，零号金阶与一号金阶（L1 SST）一同熔炼。重叠区间归并排序，杂质化烟，嵌进一号金阶。一号金阶容量递增十倍，层层向下沉降。

山下石天霸察觉异动，调动算力疯狂砸入！灌账暴涨，冰心如暴雪砸落，零号金阶堆积上百块玉简！莫寻拼命催动地火，可下层容积庞大，每次归并都要将关联的数十块玉简搬出重写。

写入一斤新账，底层为了排序整理，竟硬生生搬写了上百斤岩石！写放大（Write Amplification）！

熔炼赶不上落盘之速，千叶楼剧烈震颤，地脉濒临崩解！

嗡——！

后土深处骤然响起震天钟鸣！一道森寒玄黑铁闸自天地规则轰然坠落，死死切断经脉与晨露之泉的通路！

停写自保（Write Stall / write stall）！

天地铁闸横空降临，新写瞬间切断！晨露凝固，冰心停摆，狂暴灌账被挡在门外。莫寻真元骤停，神识如坠玄冰，彻底僵死！

护法阵外，执事见莫寻浑身僵直，吓得尖叫：“坏了！全停了！快砸开丹田填灵石！冲开铁闸！”

执事抓着极品灵石疯了一样扑上去。

“住手！”一只铁铸大手猛然探出，狠狠钳住执事手腕！

是掌门！掌门面容冷峻如铁，厉声喝止：“盲目加灵石救不了命！单机鉴爆裂的教训还不够吗？！莫寻体内雷火暗涌，这是后土自护！退下！”

执事被按在地上，灵石滚落一地，冷汗湿透后背。

识海中，莫寻艰难发问：“真君……这是什么意思？天地铁闸切断写入，难道后土新法走不通，走火入魔坏掉了？！”

“蠢材！慌什么！”玄衡痛骂，“谁告诉你停下来就是坏了？这叫停写自保（write stall）！库房工匠正在整理书架，头顶若不管不顾往里倒矿石，整座楼都要塌！天道降铁闸停笔，是在救你的命！是在强行挡住外面的灌账，给底层争取喘息归并的一线生机！”

莫寻稍定，追问：“难道世间就没有一种法门，既能写得快，又能读得快，还不占后土空间？”

“放屁！天地万物皆有代价！”玄衡厉喝，“读快、写快、省空间，此乃天地三魔！在后土大道中，三魔不可兼得！想读得快，底层就得严丝合缝逐层整理，必须忍受淬火搬运的写放大；想写得快不整理，门槛就会被乱纸塞满，读起来慢如蜗牛，后土也被撑爆；想省空间压缩到极致，读写开销便翻倍暴涨！天下大罗金仙也休想占尽便宜！分层金阶之妙，就是以适度写放大换取读与空间的永固！现在天道铁闸挡住了外乱，还不赶紧收拾底层的烂摊子！”

怒喝劈碎恐慌，莫寻心头雪亮：停写不是破灭，而是喘息生机！

他不再冲击铁闸，借着外写断绝的死寂全力催动真火！零号金阶堆积的玉简被条分缕析熔解、归并、排序。百草峰千万假账化为灰烬，三万命牌化作金线，顺畅沉入一阶、二阶、三阶……

当最后一块重叠玉简完美融入下层——

咔哒！停写自保的铁闸禁制应声碎裂！

外界积蓄的灵气如春江解冻轰然回流！晨露如泉，冰心若镜，七层金阶巍然屹立。先写内存再分层压盘，整理不及便停笔自保！

轰！千叶楼顶一道华光冲破暮色！

一颗浑圆厚重、铭刻着七阶道纹与枯荣奥义的万象金丹悬于丹田正中！万象金丹，成！

三万弟子命牌尽数安睡后土，任凭百草峰灌入多少流水，尽被千叶楼吞吐消化！

护法阵外，掌门眼中爆发出灼灼神采；执事瘫坐在地看着七彩霞光，嘴唇颤抖。

未等莫寻收功，山脚下突然传来一声怨毒刺耳的狂笑！

“好一个太数门！竟能吞下本少主的千万灌账，还能借势结丹？！”

山门牌楼下，石天霸面容扭曲。他看着百草峰流水被尽数化解、后山金丹异象冲天，杀机暴涨！

“三日之约？本少主现在就送你们归西！”

石天霸咬破舌尖，一口精血狠狠喷在山门阵角悬浮的那枚巨大贺礼符上！

轰！大典第一天留下的贺礼符骤然崩解，爆发出滔天血煞黑光！石天霸疯狂结印引动杀机，狞笑声响彻苍穹：“就算结成金丹又如何？任你后土千叶楼再能存账，莫寻，你终究只有一具肉身！太数门，你们终究只有一座孤峰！”

“给我引——单点天劫！”

轰隆隆——！！！

天地剧变，方圆千里瞬间化为永夜！紫黑色灭绝劫云层层压下，森白狂雷撕裂长空，誓要抹杀一切单点存在的恐怖天威，死死锁定了翠微峰顶！

单点必亡！天道要直接轰碎肉身，将整座翠微峰抹平！

玄衡真君神色凝重如冰：“小子，单点死穴被他引动了！金丹再稳，你也只有一具肉身！若无法在天雷下凑齐多数派〔过半数同意才算数〕共识，今夜便是山崩人亡！”

罡风猎猎，劫雷狂暴下压。莫寻手按青石迎着雷光仰望苍穹，眼底战意如烈火狂燃。
